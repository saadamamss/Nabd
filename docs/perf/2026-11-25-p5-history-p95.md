## What this is and is not

This measures the history read path alone: the SQL function, the door, JWT validation,
and the wire. It is **not** the plan/09 §4.1 referee run, which requires the **Sustained**
profile (2,000 readings/sec for 10 minutes) as the rider. That profile was deliberately
not run on the owner's laptop (RULES §5: heavy load tests run on staging), so this row
**does not fill** spec 04's "p95 < 2 s under the query storm" box. It is a query-only
number, recorded with its data volume so it cannot be mistaken for the DoD measurement.
